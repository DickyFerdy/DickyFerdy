## 🚀 Featured projects

### 📚 [Telaah](https://github.com/DickyFerdy/telaah)
A research assistant for reading scientific papers. Ask a question, get an answer with citations that highlight the exact text in the PDF, and it politely refuses when the paper doesn't have the answer.
`Next.js` `FastAPI` `PostgreSQL + pgvector` `Gemini API` `Docker`

### 🏫 [CampusReport](https://github.com/DickyFerdy/campus-report)
A campus facility reporting system with separate student and admin portals: photo evidence, status tracking, bulk actions, CSV export, and basic security hardening.
`PHP` `MySQL` `Bootstrap 5`
